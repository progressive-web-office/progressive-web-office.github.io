# Reading and reviewing

Word and OpenDocument texts, Markdown notes and PDF files can be read the
same way: page by page or scrolled, one or several pages side by side, with
the same buttons and keyboard shortcuts, and comments added as you read.

## Review mode of text documents

Click **📖 Review mode**, first in the toolbar of a text document (or press
<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>R</kbd>). The editing toolbars make way
for the review bar. The command palette (<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd>, type *review*) offers it too, even for a read-only document.

In review mode:

- the document is laid out as pages, like a PDF file; a page break in the
  document starts a new page;
- the text cannot be changed, but it can be selected and **commented**
  (<kbd>c</kbd>, or 💬); comments are listed beside the pages and saved with
  the document as usual (Word, OpenDocument, Markdown);
- **✎ Edit** (or <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>R</kbd> again) goes back to
  editing.

The pages of the review mode are a screen layout (US Letter, the width of
the editor's page): they do not always match the pages of the printed
document.

## Review mode of PDF files

PDF files are always shown as pages, with the same bar. **📖 Review mode**
(or <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>R</kbd>), first in the PDF toolbar,
puts the correction tools in front: **🖍 Highlight** and **💬 Note** stay in
the bar, the form and signature tools are hidden and the annotations panel
is shown (it explains how to annotate while it is empty). Select text and
press <kbd>c</kbd> to highlight it and write a comment; without a selection,
<kbd>c</kbd> then a click places a note. The annotations are saved in the PDF
file (see [PDF](./pdf)).

## Page by page or scrolled

**📄 Page by page** shows one spread at a time, with no scrolling: the next
spread replaces it (<kbd>k</kbd>, <kbd>Space</kbd>, the mouse wheel at the
bottom of the page…). **📜 Scroll** shows the pages one after the other.
<kbd>s</kbd> switches between them. Choose 1, 2, 3, 4 (or 6 for PDF files)
pages side by side, the whole page (↕) or the width (↔). The choices are
remembered.

## Full screen without distractions

⛶ (or <kbd>f</kbd>) puts the browser in full screen and hides everything but
the pages, the review bar and the comments. <kbd>Esc</kbd> or <kbd>f</kbd>
leaves it.

## Speed reading

**⚡ Speed reading** (in the toolbar of a text document, a Markdown note or
a PDF file, in the command palette, or <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>S</kbd>)
shows the text one word at a time in the middle of the window, so that the
eyes do not move (rapid serial visual presentation, RSVP). It starts from
the cursor, or from the current page of a PDF, paused on the first word.

- The letter the eye fixes, about a third into the word, is in colour under
  a fixed mark.
- A word stays longer after a comma, at the end of a sentence or of a
  paragraph, and when it is long; each heading is shown on its own.
- **Speed**: 100 to 1000 words per minute (300 at first), remembered;
  **Words at a time**: 1, 2 or 3 (never past the end of a sentence).
- The progress and the time left are shown below; while paused, the whole
  sentence around the word too (and screen readers read it — not each word).
- **Done** or <kbd>Esc</kbd> goes back to the text, the cursor (or the page
  of the PDF) at the last word read.

| Key | Action |
|---|---|
| <kbd>Space</kbd> | Read / pause |
| <kbd>←</kbd> / <kbd>→</kbd> | Previous / next word |
| <kbd>Ctrl</kbd>+<kbd>←</kbd> / <kbd>Ctrl</kbd>+<kbd>→</kbd> | Start of the sentence (or the previous one) / next sentence |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Faster / slower, by 25 words per minute |
| <kbd>Esc</kbd> | Back to the text |

## Keyboard shortcuts

Single keys, when the cursor is not in a field (⌨ or <kbd>?</kbd> lists them):

| Keys | Action |
|------|--------|
| <kbd>k</kbd> <kbd>n</kbd> <kbd>Page Down</kbd> <kbd>Space</kbd> <kbd>→</kbd> | Next page (or spread) |
| <kbd>j</kbd> <kbd>p</kbd> <kbd>Page Up</kbd> <kbd>Shift</kbd>+<kbd>Space</kbd> <kbd>←</kbd> | Previous page |
| <kbd>g</kbd> <kbd>Home</kbd> / <kbd>G</kbd> <kbd>End</kbd> | First / last page |
| <kbd>+</kbd> <kbd>-</kbd> | Zoom in / out |
| <kbd>w</kbd> / <kbd>h</kbd> <kbd>0</kbd> | Fit the width / the whole page |
| <kbd>1</kbd> … <kbd>4</kbd> | Pages side by side |
| <kbd>s</kbd> | Page by page or scrolled |
| <kbd>c</kbd> | Comment the selection (PDF: highlight it, or place a note) |
| <kbd>]</kbd> / <kbd>[</kbd> | Next / previous comment |
| <kbd>/</kbd> | Find |
| <kbd>f</kbd> | Full screen without distractions |
| <kbd>?</kbd> | The list of shortcuts |
